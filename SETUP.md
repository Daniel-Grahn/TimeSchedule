# Getting started

## PostgreSQL
- Download postgreSQL 17.
  - Write the password down.
  - Unclick Stack builder.
- When downloaded, open up SQL Shell (psql)
- Log in using postgres as username and the password you selected.
- Once in, create the database:

```sql
    CREATE DATABASE worksync;
```

- Check if the database exists after creation:

```sql
    \l
```
